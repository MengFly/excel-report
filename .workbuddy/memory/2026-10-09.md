## 现成 xlsx→网页回显方案调研（承接上一节的 X1 质疑）

- 产出 `doc/xlsx-html-preview-research.md`（5 节）。**核心结论：现成方案无一满足"ECharts 回显图表"这条硬需求** ⇒ 维持路径 X 不改。
- 分类事实：Aspose.Cells（`com.aspose:aspose-cells`，`HtmlSaveOptions` 无"图表转可交互数据"开关 ⇒ 走"图表→图片"渲染；$1199/$3597/$23980 三档；**评估版强制插一个水印 sheet 且永远是最前活动 sheet** ⇒ 不能上生产）；Spire.XLS 免费版（.xlsx 读写无限制，但**转 PDF/其他格式只前 3 页**；$999 档）；POI `ToHtml`（无图片无图表）+ e2h（README 自述局限、无 release）；LibreOffice headless（免费、样式保留，但**图表变图片文件**、部署重且**服务器缺字体会直接改变列宽/换行**、只能拿到 HTML 拿不到结构化数据）；Univer（Apache-2.0 核心，但**图表/透视表/协同属 Pro 商业扩展**，且违反用户"无第三方前端框架"约束 ⇒ 只当 schema 参考）；Syncfusion Java 侧细节未核实。
- **决策轴不是保真度而是"静态快照 vs 可交互数据"**：只要静态快照 ⇒ 直接买 Aspose，别自研；要有交互/语义联动 ⇒ 只能自研读回层。
- **与 excel-report 链路契合度（最关键一列）**：商业/开源方案都要求"先有 xlsx 文件" ⇒ 双遍开销（导出+解 OOXML），且**模板语义全丢**（哪个组件？对应哪个字段？合并区是表头还是分组？）⇒ 任何"报表态交互"（表头联动、图表下钻、hover 显示 SpEL）都不可能做。
- **采纳的折中**：Aspose.Cells 作为**测试期保真度对照基准**（渲染同一 xlsx 与自研 HTML 截图比对，比手写期望值靠谱），不进生产。
- **未验证边界**（下次别当已核实结论用）：Aspose HTML 模式图表的具体产物形态未跑实测；Spire 转 HTML 保真细节未跑；LibreOffice 拍平合并区为 colspan 是推断；各家在 Chrome 的像素表现未测。

## 样式组合时机追问 → recorder 方案设计（code-analyzer，未动代码）

- **用户追问"如果要改要怎么改"**（歧义：指 recorder 还是 render 期前移；按推荐路径 recorder 出方案，render 前移仅附代价清单）。
- **事实核查（决定 API 形态）**：① 插件只调 `exportTemplate`（`ExcelExporter.kt:54`），不碰 `exportSheet` ⇒ `exportSheet` 返回类型 void→ReportContext 对插件零影响（源码级；binary 层面插件用固定 jar 1.5.1 也不受影响）；② `Point`/`Size` 是 `@Data` 可变值对象，暴露活引用与既有先例一致（`StyleHolder.getStyle()` 同样返回活引用）；③ `getCellSpan` 13 个调用点覆盖全部 8 个组件（Text/Link/Span/Image/Chart/List/Table/TableNew）⇒ spans 覆盖完备；④ `ExcelCellSpan` 私有持有 `point/size/styleMap` 且 **styleMap 就是最终合并样式**（构造→`getCellSpan` 传入时已合并完）⇒ 加 3 个 getter 即可直读。
- **recorder 方案 = 3 文件 ≈ 15 行**：`ExcelCellSpan` 加 `getPosition()/getSize()/getStyleMap()`；`ReportContext.getCellSpans()` 返回 unmodifiableList；`ExcelReport.exportSheet` 返回类型 void→ReportContext。零触及 export 路径 ⇒ 字节级 A/B 天然等价。
- **核心收益**：样式来源从"POI CellStyle 反向解码"（XSSFColor/border/twips 全套踩坑）变成"StyleMap 字符串表直读"，starter 端映射表直接按 keyId 写；merge 几何不用再从 getMergedRegions 反推。时序无需新钩子：exportTemplate 返回时 applyCellWidthHeight（含 finalizer）已跑完。
- **render 期前移方案维持否决**（上轮结论），完整代价 = CellSink 中间层 + 3 组件构造期生成 cell 节点 + StyleChain 迁出 ReportContext + GridLayout 虚拟包装节点处理 + DEFAULT_STYLE 注入点迁移 ≈ 12-15 文件，与台账三.6"代价与收益不成比例"同判。
